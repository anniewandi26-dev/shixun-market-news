# 市讯

A股 / 港股 / 美股行情看板 + 股票知识 + 财经新闻。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（通常是 `http://localhost:5173`）。

页面路由：

- `/` 首页
- `/market` 行情
- `/knowledge` 知识
- `/news` 新闻

## 多语言（36 种）

- 打开网站时按 **IP 所在国家/地区** 自动匹配语言（可点「跟随 IP」重新匹配）
- 顶栏可 **手动选择** 任意语种；手动选择会记住，直到你再点「跟随 IP」
- 导航、市讯品牌、行情/知识/新闻的标题与正文都会跟随当前语言（正文首次翻译会稍慢，结果会缓存）

```bash
# 重新生成 36 语种 UI 词典
npm run i18n:build
```

## 更新节奏

- **股价**：页面打开期间约每 **30 秒** 同步（后台约 120 秒）
- **新闻 / 今日内容**：本地时间 **08:00 / 20:00** 各刷新一次；打开时若不是当天数据会立刻重拉

```bash
# 手动立刻刷新并写入 public/data/daily-bundle.json
npm run refresh

# （可选）安装 Windows 计划任务，每天 8 点与 20 点自动执行
npm run schedule:install
```

## iPhone Safari 访问

电脑执行：

```bash
npm run dev
```

终端会打印 Network 地址（如 `http://192.168.x.x:5173`）。手机与电脑同一 Wi‑Fi，用 Safari 打开该地址即可。

每次有人打开网站都会：

1. 立刻拉最新股价，并持续约 30 秒同步  
2. 本会话强制刷新今日新闻（防 Safari 缓存旧稿）  
3. 从后台回到前台 / 断网恢复时按需再拉

## 说明

- 生产部署时需自备后端或可 CORS 的数据源；当前代理仅在 `npm run dev` 下生效。
